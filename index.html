About This Project

CA Validation Tool is a student-built full-stack web application created using HTML, CSS, Bootstrap, JavaScript, Node.js and MySQL.

The current version performs format validation for PAN, TAN, Aadhaar, GSTIN, Email and Mobile numbers, and demonstrates authentication, dashboard design, history management and modern UI development.
