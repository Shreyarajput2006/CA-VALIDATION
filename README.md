# CA Validation Tool

A comprehensive full-stack web application designed for Chartered Accountants to validate various documents and identifiers such as PAN, TAN, GST, Aadhaar, Email, and Mobile numbers.

## Features
- **User Authentication**: Secure login and signup system.
- **Validation Services**: Aadhaar, PAN, TAN, GST, Email & Mobile Verification.
- **History Dashboard**: Track your previous validations with detailed statistics and history.

## Setup Instructions

1. **Install Dependencies**
   `npm install`

2. **Environment Variables**
   Create a `.env` file in the root directory and configure the API keys.

3. **Start the Server**
   `npm start`

The server will start on port `5001`.
